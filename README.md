# Khatam Quran Journey

saya mau buat aplikasi yang dipakai oleh tim kerohanian islam untuk khatam qur'an jadi ada user karyawan login kemudian pilih Juz Qur'an masing masing orang, jadi 1 orang pilih dan dapat 1 Juz sesuai urutan di backend. user bisa pilih kemudian dapat 1 Juz. setelah dapat 1 Juz user kemudian klik button "mulai" untuk baca al quran, kemudian kalau sudah selesai user bisa klik tombol "selesai"
